## Workload and independent reference

`make-long-context-cases.py --contexts 8192 65536 --positions middle
--output-tokens 128 --task extended-answer` constructs 8,064/65,408 input tokens.
It asks for the embedded record's code followed by integers 1..100. This produces
sustained decode instead of a short code-only answer. Placeholder output IDs are
not an oracle. The offline OmniInfer reference uses TP=8, EP enabled, C8
`int8_ds_mla`, 4096-token chunked prefill, eager execution, no prefix cache,
maximum context 65,536 and greedy decoding. `--respect-eos` stops at EOS;
both reference cases reach the 128-token output cap without EOS. Both correctly
retrieve the code (3423 and 6077). This reference run is for correctness, not a
matched performance comparison.

Reference inputs are deterministically regenerated by the retained launch script.
`reference-outputs.json` contains full output IDs/top-five log probabilities,
texts, input lengths and SHA-256 of compact JSON input ID arrays. The tokenizer
SHA-256 is `7816b7b6138024e37c508ff82321e11b5ee559289184fa18f7536a3e460d3941`.
Original full reference JSON and logs remain in the remote workspace.

## Native observations

Both runs reuse the existing frozen arena and backend. No model compilation,
workspace discovery, kernel change or graph policy change was needed.

- Mixed: 8K and 64K requests plus two short arithmetic peers, up to three native
  residents. All 272 requested output records arrive. The 8K request and both
  arithmetic peers match; the 64K request does not. The diagnostic probe fills
  remaining packed-batch capacity, so its chunk geometry differs from the HTTP
  scheduler's full-quantum policy. This is not an HTTP qualification.
- Isolated: the same 64K input alone, fifteen 4096-token prefill calls plus one
  3968-token tail, followed by 127 decode calls. All 128 output IDs are identical
  to the mixed run's 64K output, including the same first reference divergence.
  This makes concurrency-specific state corruption less likely; it does not
  identify the numerical cause.
- At step 7 the reference selects token 17 (`2`) with logprob -0.1270; token 220
  (space) is second with -2.1270. Native selects the space. The remaining output
  follows a different whitespace pattern. Do not dismiss a margin of 2 as a
  numerical tie, remove whitespace from the exact gate, or bless native output
  as the new reference.
- All eight ranks in both runs retain the 38,009,938,432-byte frozen arena and
  planned 159,221,248-byte workspace, with zero growth allocations, execution
  allocations, internal completion boundaries, rejected transfers or activation
  host transfers. Decode graphs replay; there is no prefill graph. Both native
  processes exit zero; both qualification wrappers exit one on exact output.

Diagnostic timing only (completed native ABI call, including selection and rank

The exact-output failure prevents using this as a qualified performance baseline.
